# Meus comandos

## O dia a dia
- `git status`: mostra oq mudou nos arquivos e oque está no rascunho. é um relatorio do que falta fazer 
- `git add arquivo`: deixa o arquivo em rascunho

- `git commit -m "texto"`: ele grava o rascunho no historico, como uma foto do projeto, e o testo entre aspas só descreve oque mudou na foto

- `git push`: manda pro github (commits)

## Quando preciso
- `git pull`: baixa do github oque mudou e junta com o meu trabalho
- `git switch -c nome`: cria uma branch nova e ja muda pra ela 
- `git log --oneline`: lista o historico de commits, um por linha 
-  `from x import y`: usado pra pegar somente um comado espefico em uma biblioteca enorme

## Terminal
- `cd pasta`: vai pro local da pasta escrita
- `ls`: lista os arquivos  e pastas  de onde eu estou 
- `pwd`: mostra em qual pasta  eu estou agora
